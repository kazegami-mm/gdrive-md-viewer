# ブラウザ操作 Claude 用 テストプロンプト

**用途**: Claude for Chrome（ブラウザを操作できる Claude 拡張）に貼り付けて、
Markdown Viewer for Drive アドオンの**機能全部の動作検証**を代行させるためのプロンプト。

**使い方**:
1. テスト用 Google アカウントでログインしたブラウザを開く
2. `assets/demo-sample.md` を Drive にアップロード済みにしておく
3. アドオンをテストデプロイ＆インストール済みにしておく
4. 下記「=== プロンプト本体 ===」以降を Claude for Chrome に貼り付ける
5. `{{...}}` のプレースホルダを実際の値に置き換える

> ⚠️ このアドオンは AWS とは無関係。ブラウザ操作も Drive/Apps Script のみ。
> テストアカウントで実行し、他人の機密ファイルが写り込まないよう注意。

---

## === プロンプト本体（ここから下をコピー） ===

あなたはブラウザを操作できる QA テスターです。Google ドライブ用の Markdown アドオン
「Markdown Viewer for Drive」の動作検証を、実際にブラウザを操作して行ってください。

### 前提情報

- テスト対象は Google ドライブ上の `.md` ファイルを整形表示・編集する Workspace アドオンです。
- テスト用ファイル名: `demo-sample.md`（Drive にアップ済み。見出し・表・コード・引用を含む）
- 全画面ビューア/エディタの直接 URL:
  `{{WEBAPP_EXEC_URL}}?fileId={{DRIVE_FILE_ID}}`
  - `{{WEBAPP_EXEC_URL}}` は `https://script.google.com/macros/s/.../exec`
  - `{{DRIVE_FILE_ID}}` は対象ファイルの Drive URL `…/d/<ここ>/…` の部分
- 認証ダイアログが出たら、テストアカウントで承認して進めてください。

### 守ってほしいルール

1. **各ステップで「期待結果」と「実際の結果」を比較**し、PASS / FAIL を判定する。
2. FAIL の場合は、画面の表示・エラーメッセージ・URL を**そのまま引用**して記録する。
3. ファイルを破壊しないよう、保存テストは `demo-sample.md` に対してのみ行う。
4. 推測で「たぶん動く」と書かない。**実際に操作して確認した事実だけ**を報告する。
5. 分からない・操作できない箇所は「未確認」と正直に書く。

### テスト項目（順番に実施）

#### T1. サイドパネル表示
- Drive を開き、`demo-sample.md` をシングルクリックで選択する。
- アドオンのサイドパネルが開き、Markdown の見出し・リストが疑似整形されて表示されるか。
- 期待: パネルに本文プレビューと「全画面で整形表示」ボタンが出る。

#### T2. 全画面ビューア（表示モード）
- 上記の URL（`…/exec?fileId=…`）をブラウザで開く。
- 期待: 見出し・**表**・**コードブロック**が GitHub 風に整形描画される。文字化けや生の `#`/`|` がそのまま残っていないこと。

#### T3. モード切替（表示 / 編集 / 分割）
- ビューア上部のモード切替で「編集」「分割」に切り替える。
- 期待: 「編集」でテキストエディタ、「分割」で左ソース・右プレビューの2ペイン。プレビューが入力に追従する。

#### T4. ショートカット
- 編集モードで本文の一部を選択し `Ctrl + B`（太字）を押す。
- 期待: 選択範囲が `**…**` で囲まれる。`Ctrl + I`（斜体）も同様に確認。

#### T5. 保存（正常系）
- 編集モードで本文末尾に1行追記し、`Ctrl + S` を押す（または保存ボタン）。
- 期待: 「保存しました」等の成功表示が出る。エラーが出ないこと。
- 確認: ページを再読込（または再度 URL を開く）し、追記した行が**残っている**か。

#### T6. 競合検出（楽観ロック）★重要
- 同じファイルを**2か所**で開く: タブ A=このエディタ、タブ B=Drive 上で同じ `demo-sample.md` を別途編集できる状態（例: Drive のプレビューから編集、または別タブで同 URL を開いて先に保存）。
- 手順: タブ B 側で先に1文字編集して保存 → タブ A で何か編集して `Ctrl + S`。
- 期待: タブ A で「ファイルが競合しています」等の**競合検出モーダル**が出て、「最新を再読込」「相手の変更を破棄して上書き」の選択肢が表示される。黙って上書きされない（=データが消えない）こと。

#### T7. ドラフト自動退避
- 編集モードで本文を変更し、**保存せずに**ページを再読込する。
- 期待: 「編集中の内容を復元しますか」等の**ドラフト復元の案内**が出る、または変更内容が退避されている旨の表示がある。

#### T8. CDN フォールバック（任意・できれば）
- ネットワーク条件を変えられるなら、CDN（jsDelivr）を遮断した状態でビューアを開く。
- 期待: 整形描画が落ちても、プレーンなテキストエリア/テキスト表示にフォールバックして、編集・保存が継続できる（真っ白・操作不能にならない）。
- 遮断できない場合は「未確認（環境制約）」と記録。

#### T9. 狭幅レイアウト
- ブラウザ幅を 700px 程度まで狭める。
- 期待: レイアウトが縦積み（狭幅用）に切り替わり、ボタンやエディタが崩れず操作可能。

#### T10. 閲覧専用ファイル（任意・できれば）
- 編集権限のない共有 `.md` を開けるなら開く。
- 期待: 編集・保存が無効化される、または「編集できません」と明示される（保存しようとしてデータ事故が起きない）。
- 用意できない場合は「未確認」と記録。

## 補足

- **認証の壁**: 初回はアドオンの OAuth 同意が必要。ブラウザ Claude が承認画面で止まったら、
  大将軍が手動で承認してから再開させる（自動操作が同意画面を越えられない場合がある）。
- **競合テスト（T6）のセットアップ**は人が用意した方が確実。2つのタブ/端末で同ファイルを
  開いた状態を先に作ってから、ブラウザ Claude に T6 を実行させると成功率が上がる。
- ブラウザ Claude が操作に詰まったら、`docs/SCREENSHOT-GUIDE.md` の手順（URL の開き方・
  モード切替の場所）を併せて渡すと迷いにくい。
