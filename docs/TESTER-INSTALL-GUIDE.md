# テスターさん向け インストール手順

**アプリ名**: Markdown Viewer for Drive
**これは何**: Google ドライブ上の Markdown（`.md`）ファイルを、ダウンロードせずにその場で
整形表示・編集できる Google Workspace アドオンです。

Marketplace 公開前の「テスト版」を、サイドパネルを含む**全機能**で試していただくための手順です。
少し手間がありますが、5 分ほどで終わります。

---

## 大将軍（開発者）が先にやること

テスターに**スクリプトプロジェクトを「編集者」として共有**します。

1. Apps Script エディタを開く（`clasp open-script`、または https://script.google.com で
   「Markdown Viewer for Drive」を開く）
2. 右上の「**共有**」ボタン
3. テスターの **Gmail アドレス**を入力 → 権限を「**編集者**」にして送信
4. テスターに本ガイド（このファイルの「テスターさんがやること」以降）を渡す

> ※ あわせて GCP の OAuth 同意画面（対象/Audience）の「テストユーザー」にも同じ
> Gmail を追加しておくと、認証時の未確認警告がスムーズになります。

---

## テスターさんがやること

### 1. 共有されたスクリプトを開く
- 開発者から共有された Apps Script プロジェクトのリンクを開きます
- （Google ドライブの「共有アイテム」にも「Markdown Viewer for Drive」が出ます）

### 2. テストデプロイをインストール
1. Apps Script エディタ画面の右上「**デプロイ ▼**」をクリック
2. 「**デプロイをテスト**」を選ぶ
3. 「**インストール**」ボタンをクリック
4. 「完了」を押す

### 3. 認証する
- 初回はアクセス許可を求められます。**自分の Google アカウント**で承認してください
- 「このアプリは Google で確認されていません」と出たら:
  - 「**詳細**」→「**Markdown Viewer for Drive（安全ではないページ）に移動**」→ 許可
  - （テスト版のため。要求する権限は「あなたが選んだファイルだけ」= `drive.file` です）

### 4. 使ってみる
- **Google ドライブ**を開く
- 任意の `.md` ファイル（無ければ適当なテキストを `xxx.md` という名前で作成）を
  **シングルクリックで選択**
- 画面右に **サイドパネル**が出て、Markdown が整形プレビューされます
- 「**全画面で整形表示**」ボタンを押すと、全画面ビューア/エディタが開きます
  - 上部の「表示 / 編集 / 分割」で切り替え
  - 編集して `Ctrl + S` で Drive に直接保存
- お試し用サンプル `.md` が欲しい場合は開発者にお伝えください

---

## うまくいかないとき

| 症状 | 対処 |
|------|------|
| サイドパネルが出ない | Drive を一度リロード。`.md` をシングルクリック（ダブルクリックでなく）で選択 |
| 「確認されていません」で進めない | 「詳細」→「（安全ではないページ）に移動」で進む（テスト版のため正常） |
| 全画面が真っ白 | ページをリロード（Ctrl+Shift+R） |
| 保存できない | そのファイルの編集権限があるか確認 |
